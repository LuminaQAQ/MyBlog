# 008\_线程池

和 Web 侧 Worker 类似. 主要用于分配重型任务, 充分利用资源进行结果计算.

## 基础用法

> 主线程

```ts
import { cpus } from "node:os";
import { MessageChannel, MessagePort, Worker } from "node:worker_threads";

interface TunnelMessage {
  id: number;
  value: number;
}

// 获取 cpu 数量, 用于创建多线程数
const poolSize = cpus().length;

const workers: Worker[] = [];
const channels: MessagePort[] = [];

for (let i = 0; i < poolSize; i++) {
  // 创建线程
  const worker = new Worker("./node-worker.js");
  // 创建通道
  const { port1, port2 } = new MessageChannel();

  // 此处直接通知子线程执行操作
  worker.postMessage(
    {
      id: i,
      value: Math.pow(10, Math.round((Math.random() + 10) * 10)),
      channel: port2,
    },
    [port2],
  );

  workers.push(worker);
  channels.push(port1);
}

// 此处通过监听通道端口来获取执行结果
channels.forEach((channel) => {
  channel.on("message", (msg: TunnelMessage) => {
    console.log(`线程${msg.id}返回了结果: ${msg.value}`);
  });
});
```

> 子线程

```ts
import { MessagePort, parentPort } from "node:worker_threads";

interface ParentPortMessage {
  id: number;
  value: number;
  channel: MessagePort;
}

const calc = (num: number) => {
  let total = 0;

  for (let i = 0; i < num; i++) {
    total += i;
  }

  return total;
};

// 在父端口上进行监听, 然后执行操作. 若直接执行该脚本, parentPort 为 null.
parentPort?.on("message", (msg: ParentPortMessage) => {
  const { id, value, channel } = msg;

  channel.postMessage({
    id,
    value: calc(value),
  });
});
```
